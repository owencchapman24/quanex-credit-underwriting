## Change-control rule

Any change to the committee date, cutoff, request ceiling, proposed closing,
source hierarchy, or no-transaction benchmark requires a new dated decision-log
entry. Post-cutoff outcome evidence must be stored and analyzed separately only
after the original underwriting recommendation has been frozen.
